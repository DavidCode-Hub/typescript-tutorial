a) (1) Define todos estos tipos:
   - enum Estado { Pendiente, EnPreparacion, Listo, Entregado }
   - type Tamano = "pequeno" | "mediano" | "grande"
   - type Email con TEMPLATE LITERAL TYPE: `${string}@${string}`
   - interface Producto: readonly id: number, nombre: string,
     precio: number, descuento?: number (porcentaje).

     caliente: boolean.

     type Fidelidad = { puntos: number }.
     Crea type ClienteFidelizado = Cliente & Fidelidad.
   - interface Pedido: id: number, cliente: ClienteFidelizado,
     lineas: [Bebida, number][] (tupla bebida + cantidad),

   Crea estas bebidas y este pedido:

   id | nombre    | precio | descuento | tamano  | caliente

   1  | Cafe solo | 1.5    | (no)      | pequeno | si

d) (0,5) Escribe aplicarPropina(total: number, porcentaje: number = 5):

   original. Anade COMENTADAS dos lineas que den error y explica el

h) (0,5) Escribe masCara(lista: Bebida[]): [string, number] que

j) (0,5) Escribe parsearCantidad(valor: unknown): number: si es

k) (1,5) Con filter + map + join muestra las bebidas calientes.

##############################################################
 EJERCICIO 3: ALQUILER DE VEHICULOS (10 ptos)
 Fichero: src/practica/ej3-alquiler.ts
##############################################################

Desarrolla un programa para una empresa de alquiler. Implementa
este diagrama de clases:

  <<Interface>> Alquilable
     + calcularPrecio(dias: number): number
     + ficha(): string
            ^  implements
  <<abstract>> Vehiculo
     + id: number (solo lectura)
     + marca: string
     + modelo: string
     + estado: EstadoVehiculo
     + cambiarEstado(estado): void
     + calcularPrecio(dias): number   (abstracto)
     + ficha(): string
            ^  extends                       ^  extends
  <<class>> Coche                    <<class>> Furgoneta
     - precioDia: number                - precioDia: number
     - seguroIncluido: boolean          - cargaKg: number
     + calcularPrecio(dias)             + calcularPrecio(dias)
     + ficha(): string                  + ficha(): string

--------------------------------------------------------------
PARTE A: MODELADO (4 ptos)
--------------------------------------------------------------
Interfaz Alquilable (0,5): define los dos metodos.

Clase abstracta Vehiculo (1,5):
 - EstadoVehiculo puede ser: "disponible", "alquilado" o "taller".
 - Su constructor recibe id (solo lectura), marca y modelo. El
   estado EMPIEZA en "disponible" (no va en el constructor).
 - cambiarEstado(nuevo) cambia el estado.
 - calcularPrecio(dias) es ABSTRACTO.
 - ficha() devuelve "#1 Seat Ibiza - disponible"
   (id, marca, modelo y estado).

Clase Coche (1): recibe ademas precioDia y seguroIncluido (ambos
PRIVADOS). calcularPrecio(dias) = precioDia x dias, mas 8 EUR por
dia si NO tiene seguro incluido. ficha() anade " . SEGURO" a la del
padre si lo tiene; si no, devuelve la del padre tal cual.

Clase Furgoneta (1): recibe ademas precioDia y cargaKg (privados).
calcularPrecio(dias) = precioDia x dias, mas 50 EUR fijos si la
carga supera los 1000 kg. ficha() siempre anade " . {cargaKg} kg".

--------------------------------------------------------------
PARTE B: CLASE ESTATICA Flota (4 ptos)
--------------------------------------------------------------
  <<class>> Flota
     - vehiculos: Vehiculo[]
     - ultimoId: number
     + registrarCoche(): Coche
     + registrarFurgoneta(): Furgoneta
     + listar(): Vehiculo[]
     + buscar(id): Vehiculo | undefined
     + cambiarEstado(id, nuevo): boolean
     + porEstado(estado): Vehiculo[]
     + ingresosPrevistos(dias): number

 - vehiculos (privada, estatica, array vacio) y ultimoId (privada,
   estatica, empieza en 0).
 - registrarCoche(marca, modelo, precioDia, seguro = false) y
   registrarFurgoneta(marca, modelo, precioDia, cargaKg):
   incrementan el id, crean el vehiculo, lo guardan en el array y
   lo devuelven.
 - listar() devuelve una COPIA.
 - buscar(id) devuelve el vehiculo o undefined.
 - cambiarEstado(id, nuevo) devuelve true, o false si no existe.
 - porEstado(estado) devuelve los vehiculos en ese estado.
 - ingresosPrevistos(dias) suma el precio para "dias" dias SOLO de
   los vehiculos alquilados.
 - RECUERDA: las clases estaticas NO tienen constructor.

--------------------------------------------------------------
PARTE C: TESTING (2 ptos)
--------------------------------------------------------------
Usando SOLO los metodos de Flota:
 1. Registra: Coche Seat Ibiza (30 EUR/dia, sin seguro), Coche
    Toyota Yaris (40 EUR/dia, con seguro), Furgoneta Renault Master
    (55 EUR/dia, 1200 kg), Furgoneta Ford Transit (50 EUR/dia,

 5. Deja COMENTADAS, con el error del compilador, estas tres

    new Vehiculo(...), y leer coche.precioDia desde fuera.
 6. Muestra cuantos vehiculos hay alquilados, cuantos en taller y
    los ingresos previstos para 3 dias.
 7. Busca los vehiculos 3 y 7 y muestra su ficha. Si no existe,
    "No existe", SIN if ni ternario.

##############################################################
 CONSEJOS PARA EL EXAMEN
##############################################################
 - Copia el array antes de sort: [...lista].sort(...)
 - sort() sin funcion ordena como TEXTO ([10, 9, 1] -> [1, 10, 9]).
 - Para filtrar valores opcionales usa !== undefined, no if (x).
 - toFixed(2) devuelve un string.
 - Si dice "sin if ni ternario" -> piensa en ?? y ?.
 - Las clases estaticas: todo "static", sin constructor.
 - Tipos de union de literales = el compilador te protege de
   valores no permitidos (error al asignar "perdida", etc.).
